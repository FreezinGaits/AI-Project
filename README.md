# Next-Location Prediction - Project Guide

This is a complete end-to-end Machine Learning project to predict a student's next location (Stage, Canteen, or Lab) during a college event day. It has two main parts:
1.  **Jupyter Notebook:** For Data Analysis, Model Building, and Model exporting.
2.  **FastAPI Backend & Frontend API:** A web server running the best-trained model alongside a polished UI interface to run predictions in real-time.

Here is the step-by-step guide on how to run this project yourself.

---

## Prerequisites

Make sure you have **Python** installed on your system.
Open your terminal (Command Prompt / PowerShell) and navigate to the project directory:
```powershell
cd "d:\Code Playground\AI_Project"
```

## Step 1: Install Dependencies

You'll need data-science libraries to run the notebook, and web-server libraries to run the API.
Run this command in the terminal:
```powershell
pip install pandas numpy matplotlib seaborn scikit-learn xgboost jupyter fastapi uvicorn joblib
```

## Step 2: Explore the Jupyter Notebook

The notebook (`Next_Location_Prediction.ipynb`) generates the data, analyzes it, and compares the models (Random Forest, XGBoost, Markov Chains). 

1. Launch Jupyter Notebook from your terminal:
   ```powershell
   jupyter notebook
   ```
2. Your browser will open. Click on `Next_Location_Prediction.ipynb`.
3. In the menu at the top, click **Cell -> Run All**.
4. Scroll through to see the graphs, confusion matrices, and the probability layout. 
5. *Note: Running the notebook automatically executes Cell 10.5, which trains the models and dumps them into the `model_artifacts/` folder. The web server needs this folder to work!*

*(If you skip this step, there is a shortcut script `python train_model.py` which trains and dumps the models instantly without opening the notebook).*

## Step 3: Start the Backend Web Server

Once your models are exported to `model_artifacts/`, you can start the API that powers the website UI.

1. Open a terminal in `d:\Code Playground\AI_Project`
2. Run the FastAPI server:
   ```powershell
   uvicorn app:app --reload
   ```
3. You should see an output saying: `Uvicorn running on http://127.0.0.1:8000`

*Keep this terminal open, as it powers the prediction engine!*

## Step 4: Open the Frontend App

While the FastAPI server is running (from Step 3), the frontend is automatically hosted.

1. Open your web browser (Chrome, Edge, Safari, etc.)
2. Navigate to **http://localhost:8000**
3. The UI will appear. You can play around with the drop-downs (Current location, time of day, event, crowd) and click **"Predict Next Location"**.
4. The page will ping your local Python server, run the exact same Random Forest & Markov Chain models you built in the notebook, and print the results with animated confidence bars!

---

### Project Files Overview:
*   `Next_Location_Prediction.ipynb`: The main data science notebook.
*   `info.md`: Detailed explanation of how the notebook cells and algorithms work.
*   `app.py`: The FastAPI backend server.
*   `frontend/index.html`: The UI web page.
*   `model_artifacts/`: Directory where the trained models are saved.
*   `student_location_data.csv`: The synthetic 10,000-row dataset generated by the notebook.
