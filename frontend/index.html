📊 How It Works

This system uses ensemble ML models trained on 10,000 student movement records to predict the next location.

ML Model — Uses Random Forest / XGBoost considering all contextual features for nuanced predictions.

Markov Chain — Uses transition probabilities based solely on current location for comparison.

Confidence — Shows how certain the ML model is about its prediction.
